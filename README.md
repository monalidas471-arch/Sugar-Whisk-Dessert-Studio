# Sugar-Whisk-Dessert-Studio

Project Title: Sugar Whisk Design Studio

Project Overview:
Sugar Whisk Design Studio is a multi-page confectionery brand and design showcase website. The project presents an artisanal dessert studio, featuring a homepage with studio highlights, an about page detailing the studio's background and values, a product catalog displaying pastries and prices, an international sweets showcase featuring traditional desserts from 15 different countries, and an interactive contact page.

Project Structure and Files:
- index.html: Serves as the homepage, featuring a welcoming hero section and featured studio highlights.
- about.html: Outlines the studio's creative vision, quality standards, and core philosophy.
- catalog.html: Displays a grid of confectionery items complete with images, descriptions, and pricing badges.
- countries.html: Showcases traditional desserts and sweets from 15 different countries across the globe.
- contact.html: Provides a form for user inquiries and custom orders.
- style.css: Manages the visual styling across all pages, including responsive grid layouts, typography, and color schemes.

Team Work Division:
- Partner 1: Developed the style.css stylesheet, index.html, and contact.html.
- Partner 2: Developed catalog.html, about.html, and countries.html.
